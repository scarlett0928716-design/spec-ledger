# examples/

一组填好的 spec + 任务账本，展示"写到什么程度算合格"：

- `inv-001-export-csv.md` — 一个小功能的 planned spec，注意第 3.1 节把现有行为锁死、第 9 节自检记录里有一条"待人裁决"的领域假设
- `CONTEXT.md` — 填好的词汇表：正式术语、主键/主路径、禁用说法、以及两条"待确认"项（一条已裁决、一条未裁决）
- `inv-001-export-csv.tasks.md` — 对应的任务账本，做到一半的状态：T1–T3 已提交，T4 测试已绿未提交，"阻塞与裁决记录"里记了人的裁决

业务背景是虚构的资产盘点系统，不含任何真实数据。
