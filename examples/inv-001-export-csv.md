# Spec: 盘点结果导出 CSV

## 1. 目标

让管理员把一次盘点任务的结果导出为 CSV，供财务在 Excel 里核对差异。

## 2. 背景

现在差异只能在页面上看，财务要逐条抄。已有的 Excel 导出走 openpyxl，财务反馈打开慢、且他们的旧系统只认 CSV。

## 3. 设计方案

### 3.1 边界（什么锁死）

- 入口：`GET /tasks/{task_id}/export?format=csv`，与现有 `format=xlsx` 并列，**现有 xlsx 行为不变**
- 返回：`text/csv; charset=utf-8-sig`（带 BOM，Excel 直接打开不乱码），文件名 `inventory-{task_id}.csv`
- 列顺序与 xlsx 导出完全一致（复用同一个列定义）
- 权限：沿用现有导出接口的权限检查，不新增

### 3.2 实现空间

- CSV 生成用标准库 `csv` 还是手写拼接，实现者定
- 是否流式输出（StreamingResponse），实现者按数据量定

### 3.3 不做什么

- 不改 xlsx 导出
- 不加筛选参数（只导出全部结果）
- 不处理"差异督办"状态列（留给 inv-002）

## 4. 验收标准

- [ ] AC-1：`format=csv` 返回 200，Content-Type 为 `text/csv; charset=utf-8-sig`
- [ ] AC-2：响应体首三字节为 UTF-8 BOM
- [ ] AC-3：首行列名与 xlsx 导出的表头逐项相等
- [ ] AC-4：数据行数 = 该任务的盘点结果条数
- [ ] AC-5：`format=xlsx` 的响应与改动前字节级一致（特征测试保证）
- [ ] AC-6：无权限用户请求返回 403，与 xlsx 路径一致

## 5. 行为面清单

| 行为面 | 当前表现 | 是否必须保持 |
|---|---|---|
| 返回结构（xlsx） | openpyxl 生成，列定义在 `app/export.py::COLUMNS` | 是 |
| 异常路径 | 任务不存在 404，无权限 403 | 是 |
| 数据库副作用 | 无写入 | 是 |

## 6. 测试计划

- 特征测试：锁住 xlsx 导出的表头与 403/404 路径
- 回归测试：AC-1 … AC-6
- 边界用例：结果为 0 条时只有表头；字段含逗号/换行时正确转义
